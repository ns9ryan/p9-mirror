# deployment

P9 外网服务器部署配置管理。

统一管理各服务器的 Docker Compose、Nginx、服务配置及相关部署文件，支持本地编辑、版本管理和远程文件同步。

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `ec2-v2-dev-app-01` | 应用服务器 01 |
| `ec2-v2-dev-app-02` | 应用服务器 02 |
| `ec2-v2-dev-web-01` | Web 服务器 |
| `ec2-v2-dev-infra-01` | 基础设施服务器 |

## 管理约定

- 一级目录对应服务器主机名。
- 子目录尽量与服务器实际部署路径保持一致。
- 配置文件统一在本地编辑，确认后同步至对应服务器。
- 服务器文件同步统一遵循 JMS 堡垒机访问策略。
- 禁止提交密码、私钥及其他敏感信息。
