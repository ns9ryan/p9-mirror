# 部署配置

本目录用于整理和维护各环境、服务器及服务的部署配置文件、配置模板和相关说明。

## 内容范围

- Docker Compose 服务编排配置
- Nginx 及 Web 服务配置
- PostgreSQL、Redis、Kafka 等基础服务配置
- 应用服务运行配置及模板
- 部署、维护相关脚本和说明文档

## 目录组织

根据服务器角色、节点及服务职责组织目录。

目录结构以实际部署情况为准，保持清晰、直观，避免为尚未使用的环境或服务提前建立目录。

## 配置管理

- 配置文件尽量与实际部署结构保持对应，方便查找和维护。
- 通用配置与环境差异配置合理区分。
- 可复用的配置模板与实际运行配置分开管理。
- 不存放运行日志、业务数据、数据库备份及构建产物。

## 安全要求

- 不保存真实密码、Token、API Key、数据库凭据及私钥等敏感信息。
- 敏感配置单独保管，不纳入版本管理。
- 涉及服务器 IP、域名、主机名、端口及网络拓扑等基础设施信息时，注意信息安全。
- 配置变更前后检查文件内容，避免误包含敏感信息。
